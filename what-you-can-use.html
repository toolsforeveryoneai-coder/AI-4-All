I need to process confidential documents without sending them out

Before you choose. A vendor will not tell you that a local model is only as good as the machine underneath it: the same model on 16 GB of video memory is a different product from the same model on a 64 GB card. Check that your workflow — document scanning, long files, many pages at once — fits the memory you actually have. Also read the licence line yourself: 'open weights' does not mean free to use commercially in every case, and the two options above both use a permissive Apache 2.0 licence, which is the safe default for a business.

Gemma 4 12Bavailable today

Reads documents, images, video and audio locally on a laptop — the model card states the small Gemma 4 models are designed for efficient local execution on laptops and mobile devices. Confidential documents never leave the machine.

What it costs. Runs on a laptop or a desktop with a consumer graphics card — the model card documents laptop-class hardware as the target. No cloud subscription, no per-token bill.

I want to write code without paying a fortune

Before you choose. What a vendor will not tell you: the price you see is the input price, and code generation is output-heavy — a long session spends more on output tokens, where the multiplier between the two options here is over twenty times. The cheapest headline rate also comes with a schedule change in the next 24 hours (DeepSeek moves to peak/off-peak on 16 August). If your code work runs in bursts, check which hours are peak before committing to a bill.

A fast general model good at coding tasks, sold per token with one of the lowest prices in the market.

  • $0.22 / $0.66 per 1M tokens — off-peak rate from 16 Aug 2026
  • $0.44 / $1.32 per 1M tokens — peak rate from 16 Aug 2026

I need a machine to read a lot of text

Before you choose. What a vendor will not tell you: for bulk reading, the input price is only half the story — the real lever is caching. DeepSeek's cache-hit rate ($0.0028) is fifty times cheaper than its cache-miss rate, so if your pipeline re-reads the same documents, engineering the cache is worth more than picking the cheapest headline price. For a fixed corpus, the cheapest total bill depends on how much of it you re-read.

One option clears the bar today.

DeepSeek V4 Flashavailable today

Reads large volumes of text through an API at a very low per-token cost, suitable for batch summarising or extraction.

What it costs. $0.14 per 1M input tokens (cache miss) today; $0.28 per 1M output. Cache hits are drastically cheaper at $0.0028 per 1M, which rewards repeated reads of the same corpus. Off-peak pricing from 16 Aug: $0.22 input, $0.66 output.

  • $0.14 per 1M input tokens — cache miss, today's rate
  • $0.0028 per 1M input tokens — cache hit rate

I want it to work on its own while I do something else

Before you choose. What a vendor will not tell you: an agent that 'works on its own' spends tokens you do not see — every internal step, every tool call, every retry is billed, and the official xAI docs say it outright: costs scale with query complexity because the agent decides how many tools to call. The per-token price is a floor, not a ceiling. If you need one task done reliably, a cheaper non-agentic model in a tight loop can beat a frontier agent on total cost. Budget for the loop, not the headline rate.

One option clears the bar today.

Grok 4.6available today

Runs multi-step tasks with tools — the official docs state the agent autonomously decides how many tools to call — and is billed per token.

What it costs. $2.00/$6.00 per 1M tokens (short context), $4.00/$12.00 (long). The official docs describe server-side tools as billed on token usage plus tool invocations, without publishing a fixed rate.

  • $2.00 / $6.00 per 1M tokens — short context
  • $4.00 / $12.00 per 1M tokens — long context (500k window)
